## Steps

1. **DAL** — `Queries/GuideSearchQuery` (filter fields + page/size); `IGuideProfileRepository.SearchAsync(query, ct)`: always Approved + complete, then optional filters, order (Q2), `Skip/Take`, total count → `PagedList<GuideProfile>`; include User, languages, specializations.
2. **BLL** — `Infrastructure/ICountryProvider` + `CountryProvider` (ISO list, `IsValid(code)`); `DTOs/Search/GuideSearchFilter`, `GuideCardDto`, `SearchFilterOptionsDto`, `LookupDto`, `CountryDto`; `GuideSearchFilterValidator`; `GuideMappingProfile` (`GuideProfile` → `GuideCardDto`), `LookupMappingProfile`; `ISearchService` + `SearchService`; register in `AddBusinessLogic`.
3. **PL** — `Controllers/SearchController.Index(SearchViewModel, ct)`: `ModelState` → map → `SearchAsync` + `GetFilterOptionsAsync`; `SearchViewModel` (filters + dropdown lists + results + paging), `GuideCardViewModel`; `PublicViewModelProfile`.
4. **View** — `Views/Search/Index.cshtml` + `wwwroot/css/Search/Index.css`: sidebar filters (country, language, specialization, min/max price), card grid (photo/initials, name, city/country, languages, rating + count, price/hour, "View profile" → `GuideProfile/Details/{id}`), pager, empty state, validation summary + `_ValidationScriptsPartial`; layout "Find a guide" links already point here.
5. **Build + manual check** — `dotnet build`; demo seed: approved complete guides appear; a Pending, a Rejected and an approved-but-incomplete guide never appear; each filter alone and combined; min > max refused.
