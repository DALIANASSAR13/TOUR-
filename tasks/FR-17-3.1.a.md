## Steps

1. **DAL** — `IBookingRepository.GetDueForAutoCancelAsync(nowUtc, pendingCreatedBeforeUtc, ct)` + `BookingRepository`: tracked; `(Pending && CreatedAtUtc <= pendingCreatedBeforeUtc) || (Accepted && PaymentDeadlineUtc <= nowUtc)`. The cutoff is passed in so the 24 h stays in `BookingRules` (Q1).
2. **BLL** — `DTOs/Job/JobRunSummary`; `IBookingStatusJobService` + `BookingStatusJobService.RunAsync(ct)`: load due rows; for each, `Apply(Cancelled, Actor.System, now, NoGuideResponse | NotPaid)`, `SaveChangesAsync` per booking, `ConcurrencyException` → skip + count; return summary. Register Scoped in `AddBusinessLogic`.
3. **PL** — `BackgroundJobs/BookingStatusJob : BackgroundService`: `PeriodicTimer(options.Interval)`; each tick: new scope → `RunAsync` → log summary at Information when anything changed; catch + log errors, keep looping. `AddHostedService<BookingStatusJob>()` in `Program.cs`.
4. **Config** — `appsettings.Development.json`: `BookingJob:Interval = 00:00:30` for testing (prod stays 5 min). Run once at startup, then every interval (Q2).
5. **Build + manual check** — `dotnet build`; seed has Emma→Omar Accepted (deadline ≈ 22 h) and Pendings created 3–6 h ago. To test without waiting: set `CreatedAtUtc` / `PaymentDeadlineUtc` in the past in SQL, wait one interval, refresh Requests / My Bookings.
