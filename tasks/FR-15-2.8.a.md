## Steps

1. **DAL** — `IBookingRepository.GetForTouristAsync(touristId, ct)` in `ISpecificRepositories.cs` + `BookingRepository`: filter `TouristId`, include `GuideProfile`→`User` (name, city/country, photo, `TimeZoneId`), `Payment`, `Review`; order by `CreatedAtUtc` desc; `AsNoTracking`.
2. **BLL** — `DTOs/Booking/BookingDto` (id, guide name/location/photo, type, start/end UTC, guide time zone, hours/days, billable hours, price/hour, total, status, cancellation reason, payment deadline, created, review rating/comment); `BookingMappingProfile` (entity → DTO); `IBookingService` + `BookingService` with `GetForTouristAsync` only; register in `AddBusinessLogic`.
3. **PL** — `Areas/Tourist/Controllers/BookingsController.Index` (`[Area("Tourist")]`, `[Authorize(Roles = Roles.Tourist)]`); `MyBookingsViewModel` + `BookingItemViewModel` (local date/time text, status note, flags `CanPay/CanWithdraw/CanReview`) in `TouristViewModelProfile`; optional `?status=` filter with counts.
4. **View** — `Areas/Tourist/Views/Bookings/Index.cshtml` from screen 6: status chips with counts, card per booking (badge, guide, date line, status note, price line, buttons by status), empty state; nav link "My Bookings". Buttons for 2.8.b/2.9/3.2 rendered disabled or as links to placeholders.
5. **Build + manual check** — `dotnet build`; insert sample bookings for 2 tourists; log in as each.
