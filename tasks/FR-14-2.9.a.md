## Steps

1. **DAL** — `IPaymentRepository.GetByBookingAsync(bookingId, ct)` + `PaymentRepository`; expose `Payments` on `IUnitOfWork`; register in `AddDataAccess`. Check that the `Payment` entity and its configuration (unique `BookingId`, `TransactionReference` max 36, `Amount` `decimal(10,2)`) exist; add them and a migration only if missing.
2. **BLL** — `CheckoutDto` (booking id, guide name, type, start/end, hours or days, billable hours, price per hour, total, deadline, guide time zone); `IPaymentService.GetCheckoutAsync(touristId, bookingId, ct)`: load booking → not found / not owner → same "not found" fail → not `Accepted` → fail → expired (`BookingExpiry.IsExpired`) → fail → payment exists → fail → map to `CheckoutDto`. New `PaymentMappingProfile` (`Booking` → `CheckoutDto`); register the service in `AddBusinessLogic`. Reuse the messages and error codes from 2.8.b; add a code only if one is missing.
3. **PL** — Tourist `PaymentsController.Checkout(int id, ct)` `[HttpGet]`: call the service; on failure put the message in the `BookingError` flash and redirect to My Bookings; on success map to `CheckoutViewModel` and show the view. Add the mapping to `TouristViewModelProfile`.
4. **View** — `Areas/Tourist/Views/Payments/Checkout.cshtml` from UI screen 4: booking summary, total, "Pay before …" in the guide's local time, test-mode banner, Pay button disabled until 2.9.b (Q1), "Back to My Bookings". In `Bookings/Index.cshtml`, point the Pay button on Accepted, non-expired cards to `Checkout` (new `CanPay` flag set in `SetAllowedActions`, Q2).
5. **Build + manual check** — `dotnet build`; DevLogin as Emma: open checkout for an Accepted booking; type the URL by hand for a Pending, Rejected, Cancelled (withdrawn) and Confirmed id; John opens Emma's id; open one past its deadline.
