## Steps

1. **DAL** — `IReviewRepository.GetForGuideAsync(guideId, page, pageSize, ct)`: newest first, include tourist (name, country), `Skip/Take`, total → `PagedList<Review>`.
2. **BLL** — `DTOs/Guide/PublicGuideProfileDto` (profile fields + language/specialization names + `PagedList<ReviewDto>`), `DTOs/Review/ReviewDto` (rating, comment, date, tourist first name + country); `GuideMappingProfile` (`GuideProfile` → `PublicGuideProfileDto`), `ReviewMappingProfile`; `IGuideProfileService` + `GuideProfileService.GetPublicProfileAsync` (`GetWithDetailsAsync` → `GuideRules.IsBookable` else `NotFound` → reviews page); `SearchRules`-style `ProfileRules.ReviewPageSize`; register Scoped.
3. **PL** — `Controllers/GuidesController.Details(int id, int page = 1, ct)`: fail → `NotFound()`; `PublicGuideProfileViewModel` + `ReviewItemViewModel`; maps in `PublicViewModelProfile`. Repoint "View profile" (2.4.a) and "Guide profile" (2.8.a) links to `Guides/Details/{id}`.
4. **View** — `Views/Guides/Details.cshtml` + `wwwroot/css/Guides/Details.css`: header card (initials, name, location, stars + count or "New guide", experience, price/h, Book button), About, languages/specializations tags, reviews list with pager; Book shown to anonymous + Tourist, hidden for Guide/Admin.
5. **Build + manual check** — `dotnet build`; Omar (reviews), Salma (no reviews → 0), Mahmoud (incomplete → 404), Ahmed (Pending → 404), Laila (Rejected → 404), unknown id → 404; Book as Emma opens 2.6 form; Search → View profile works.
