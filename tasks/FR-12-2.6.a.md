## Steps

1. **BLL Domain** — `BookingRules.HoursPerDay` (+ Min/Max Hours/Days if missing); `Domain/Interfaces/IPriceCalculator` + `Domain/PriceCalculator` (pure, no DB, no time); register Singleton.
2. **BLL DTOs + validator** — `DTOs/Booking/CreateBookingRequest` (guide id, type, start local date/time, hours, days), `PriceQuoteDto` (billable hours, price/hour, total, type, hours, days); `CreateBookingValidator` with the BR-04 limit rules only (24 h + same-day rules added in 2.6.b).
3. **BLL service** — `IBookingService.PreviewPriceAsync(request, ct)`: validate → load guide via `IUnitOfWork` → not bookable = `Result.Fail(NotFound)` → calculator → quote. No `SaveChanges`.
4. **PL** — Tourist `BookingsController.Create(int guideProfileId)` GET (form shell) + `PreviewPrice` POST returning JSON (quote or field errors); `CreateBookingViewModel` with `[Range]` from `BookingRules`; `TouristViewModelProfile` VM → DTO; view `Create.cshtml` with type toggle, hours/days, price box updated on change (`wwwroot/js/booking-price.js`, sends the anti-forgery token).
5. **Build + manual check** — `dotnet build`; check AC1–AC10 with a demo guide at $20/h.
